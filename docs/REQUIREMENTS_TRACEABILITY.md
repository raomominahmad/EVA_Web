# EVA — Requirements Traceability Matrix

Maps each functional requirement in `PROJECT_REQUIREMENTS.md` §5 to its implementation and its
automated tests. The requirement text there is authoritative; the summaries below are shortened.

**Verification status** means: the implementation files exist, the listed tests exist and exercise
the acceptance criteria, and all of them passed in the run recorded in `TEST_EVIDENCE.md`.

Paths are relative to the repository root. `src/domain/` is shared by the browser and the local
backend. Playwright tests (`e2e/`) run in two projects, desktop (1440×900) and mobile (375×812);
`e2e/ai-summary-enabled.spec.ts` runs against a build with `VITE_AI_SUMMARY_ENABLED=true`.
